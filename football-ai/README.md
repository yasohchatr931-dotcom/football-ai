# FOOTBALL AI – étape 1 (socle)

Contenu : accueil, matchs (aujourd'hui, demain, semaine, en direct, terminés, à venir), recherche, logo, favicon, SEO de base, date de synchronisation.
Pas encore fait : équipes, compétitions, comparateur, Poisson, analyses IA, assistant, administration, pages légales.

## Mise en ligne (tout dans le navigateur)
1. Créez un compte gratuit sur github.com, puis un dépôt « football-ai ».
2. Dans le dépôt : « Add file » > « Upload files », glissez tout le contenu de ce dossier, validez.
3. Créez une clé gratuite sur football-data.org/client/register.
4. Créez un compte gratuit sur vercel.com (connexion avec GitHub), « Add New Project », choisissez football-ai.
5. Avant de valider, ajoutez la variable FOOTBALL_DATA_API_KEY (votre clé), puis « Deploy ».
Vercel vous donne une adresse en .vercel.app à partager.
